# 🏦 Loan Approval Prediction using Logistic Regression

## 📌 Project Overview

This project demonstrates how **Logistic Regression** can be used to predict loan approval decisions based on applicant information. The model classifies loan applications into two categories: **Approved** or **Rejected** by analyzing key financial and demographic factors.

The project was developed using the **Orange Data Mining Tool**, a no-code machine learning platform, making it easy to understand and implement predictive analytics in finance without programming.

---

## 🎯 Objectives

- Predict loan approval outcomes using machine learning.
- Understand the application of Logistic Regression in finance.
- Build a no-code predictive model using Orange.
- Evaluate model performance using classification metrics.
- Support data-driven lending decisions.

## 📊 Dataset Features

The model uses applicant information such as:

- Applicant Income
- Co-applicant Income
- Loan Amount
- Loan Term
- Credit History
- Education
- Employment Status
- Property Area
- Marital Status
- Loan Approval Status (Target Variable)

## 🤖 Logistic Regression in Loan Prediction

Logistic Regression is a supervised machine learning algorithm used for binary classification problems. In this project, it predicts whether a loan application should be:

- ✅ Approved (1)
- ❌ Rejected (0)

The algorithm estimates the probability of loan approval based on historical applicant data.

---

## 📈 Model Evaluation

The model performance can be measured using:

- Accuracy
- Precision
- Recall
- F1 Score
- AUC (Area Under Curve)

These metrics help determine how effectively the model predicts loan approvals.
